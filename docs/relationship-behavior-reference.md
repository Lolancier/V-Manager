# Vivi 情绪、好感与行为数据参考

本文记录当前实现中的真实字段和规则，供后续调整主动行为、创作偏好与 Live2D 表现时参考。

## 1. 本地关系档案

文件：`%APPDATA%\v-manager\agent-data\profile.json`

### affection（好感）

| 字段 | 范围/初始值 | 当前用途 |
|---|---:|---|
| `score` | 0–100，初始 12 | 决定关系阶段 |
| `stage` | 见下表 | 内部阶段 ID |
| `stageLabel` | 初识 | 界面与提示词显示 |
| `interactions` | 初始 0 | 总互动次数 |
| `touchInteractions` | 初始 0 | 有效点击/触碰次数 |
| `positiveInteractions` | 初始 0 | 正向互动次数 |
| `negativeInteractions` | 初始 0 | 明确负向互动次数 |

| 分数 | 阶段 ID | 阶段名称 | 当前表达边界 |
|---:|---|---|---|
| 0–19 | `new` | 初识 | 友好、有边界，不过分亲密 |
| 20–44 | `familiar` | 熟悉 | 更放松，可接轻松玩笑 |
| 45–69 | `friend` | 朋友 | 熟悉朋友式交流，可自然调侃和关心 |
| 70–89 | `close_friend` | 挚友 | 更信任、细致，允许适度撒娇 |
| 90–100 | `kindred` | 心意相通 | 亲近坦诚、重视共同记忆，但尊重现实边界 |

### 当前好感变化

- 普通有效消息：`+0.16`
- 消息长度至少 20 字：额外 `+0.06`
- 命中感谢、喜欢、夸奖、抱抱等正向表达：额外 `+0.62`
- 命中早安、晚安、休息、辛苦等关心表达：额外 `+0.38`
- 命中道歉表达：额外 `+0.24`
- 命中明确辱骂或强烈排斥：本次改为 `-1.6`
- 有效点击桌宠：`+0.08`
- 每日正向增长上限：`3`；负向变化不受该上限保护

## 2. emotion（短期心情）

| 字段 | 范围/初始值 | 含义 |
|---|---:|---|
| `valence` | -1–1，初始 0.1 | 愉悦度：负数偏低落/不悦，正数偏温柔/开心 |
| `arousal` | 0–1，初始 0.25 | 活跃度/唤醒度 |
| `label` | 初始“平静” | 根据两个连续值计算的中文状态 |
| `suggestedMood` | 初始 `idle` | 推荐给 Live2D 的表现 |

### 心情标签阈值

| 条件 | 标签 |
|---|---|
| `valence <= -0.45` 且 `arousal >= 0.5` | 不悦 |
| `valence <= -0.45` 且 `arousal < 0.5` | 低落 |
| `valence >= 0.5` 且 `arousal >= 0.55` | 开心 |
| `valence >= 0.5` 且 `arousal < 0.55` | 温柔 |
| 其他情况下 `arousal >= 0.65` | 活跃 |
| 其他情况 | 平静 |

### 互动影响与自然衰减

- 正向/关心/道歉通常提高 `valence`；明确负向表达降低 `0.75`，并至少进入 `-0.55`。
- 感叹、兴奋表达使 `arousal +0.2`；提问 `+0.1`；长消息 `+0.07`；普通短消息 `-0.02`；负向表达 `+0.28`。
- 无互动时，`valence` 以约 8 小时时间尺度逐渐回到 0。
- `arousal` 以约 4 小时时间尺度逐渐回到基线 `0.25`。
- 设置页“愉悦”显示值为 `(valence + 1) × 50%`，“活跃”为 `arousal × 100%`。

## 3. Live2D 当前状态

当前基础状态共 8 个：

| Mood | 中文 | 典型触发 |
|---|---|---|
| `idle` | 待机 | 普通空闲、随机动作 |
| `thinking` | 思考中 | 模型思考、日记/绘画/小游戏创作 |
| `talking` | 说话中 | 回复与语音播放 |
| `happy` | 开心 | 正向结果、创作完成 |
| `sad` | 难过 | 低落状态 |
| `surprised` | 惊讶 | 初识点击、意外信息 |
| `angry` | 生气 | 明确负向互动 |
| `blush` | 害羞 | 较高关系阶段或关心表达 |

私密空间新增的持续动作映射：

- 日记、绘画：`thinking` + `expression25`（笔记本右）+ `expression26`（笔记本左）。
- 小游戏：`thinking` + `expression27`（打游戏）。
- 创作结束或终止后清除持续动作，恢复原有待机随机动作和点击反馈。

## 4. 深层陪伴记忆与打扰反馈

文件：`agent-data/companion-memory.json`

- `facts`：事实记忆。
- `episodes`：近期经历。
- `habits`：习惯。
- `commitments`：承诺，含 `open/resolved` 状态和最近回访日期。
- `feedback.ignored`：忽略次数。
- `feedback.later`：稍后次数。
- `feedback.liked`：喜欢次数。
- `feedback.interruptionScore`：0–1 打扰评分，用于压低主动提醒频率。

## 5. 生活与自主创作状态

- `life-state.json`：主人在线/离开、连续工作分钟、Vivi 精力、休息状态、主动提醒次数。
- `vivi-sandbox/state.json`：当日首次启动时间、日记到期时间、主人最近任务完成时间、被终止后等待续作的活动。
- 只有普通创作需要“主人任务已完成 + Agent 无任务 + 电脑达到空闲时长”。
- 每日日记独立执行：当天首次启动后随机 2–3 小时到期；当天重复执行覆盖更新同一个 `diary/YYYY-MM-DD.md`。
